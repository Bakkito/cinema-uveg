Aviso de privacidad

Responsable: Cinema UVEG, proyecto académico desarrollado con fines educativos.

Datos tratados: la aplicación consulta información de películas mediante The Movie Database (TMDB). Si el usuario agrega favoritos, se almacenan el identificador de la película, su título, la ruta del póster y la fecha de registro en la base de datos local.

Finalidad: mostrar películas, consultar sus detalles y permitir guardar, consultar y eliminar favoritos.

Almacenamiento: los favoritos se guardan en una base de datos MariaDB administrada por el responsable del entorno local. No se deben introducir contraseñas, datos financieros ni información personal sensible.

Servicios externos: la aplicación consulta TMDB y puede cargar imágenes desde sus servidores. El uso de esos servicios está sujeto a sus propias políticas de privacidad.

Seguridad: el proyecto utiliza HTTPS en su entorno local y medidas de seguridad en el servidor. Estas medidas reducen riesgos, pero no garantizan seguridad absoluta.

Conservación y eliminación: los favoritos pueden eliminarse desde la aplicación. Los datos permanecen en la base local hasta su eliminación o hasta que se borre la base de datos.

Contacto: para dudas relacionadas con este proyecto académico, consulta al responsable del proyecto por el medio indicado por tu institución.

Este aviso es informativo y debe adaptarse a la identidad del responsable y a las obligaciones legales aplicables antes de utilizar la aplicación con usuarios reales.

Términos y condiciones

1. Finalidad. Cinema UVEG es una aplicación académica para explorar películas y administrar una lista de favoritos.

2. Uso permitido. El usuario se compromete a utilizar la aplicación de forma lícita y a no intentar afectar su disponibilidad, seguridad o funcionamiento.

3. Información de películas. Los títulos, sinopsis, calificaciones y pósteres pueden proceder de servicios externos. Su disponibilidad y exactitud dependen de dichos servicios.

4. Favoritos. La función de favoritos permite registrar y eliminar referencias de películas en la base de datos del proyecto. No implica adquirir derechos sobre el contenido audiovisual.

5. Propiedad intelectual. Los derechos de películas, imágenes, marcas y materiales de terceros pertenecen a sus respectivos titulares. El proyecto no reclama su propiedad.

6. Disponibilidad. Al tratarse de un proyecto académico local, no se garantiza un servicio continuo ni la conservación permanente de los datos.

7. Seguridad y uso responsable. El usuario no debe introducir información sensible ni utilizar la aplicación para actividades ilícitas.

8. Cambios. Estos términos pueden actualizarse para reflejar cambios técnicos o académicos.

9. Contacto. Las dudas sobre el funcionamiento pueden dirigirse al responsable académico del proyecto.

Al utilizar la aplicación, el usuario acepta estas condiciones de uso académico.
